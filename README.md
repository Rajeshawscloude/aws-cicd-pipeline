# AWS CI/CD Pipeline with GitHub Actions 🚀

## Overview
Automated CI/CD pipeline that deploys website to 
AWS S3 automatically on every code push to GitHub!

## How It Works
Push code to GitHub
        ↓
GitHub Actions triggers automatically
        ↓
Deploys to AWS S3
        ↓
Website updates live!

## AWS Services Used
- S3 — Host deployed website
- IAM — Secure GitHub Actions credentials

## Tools Used
- GitHub Actions — CI/CD automation
- AWS CLI — Deploy to S3

## Pipeline Steps
1. Code pushed to GitHub main branch
2. GitHub Actions workflow triggers
3. AWS credentials configured securely
4. Files synced to S3 bucket
5. Website automatically updated!

## Live Demo
Website: http://rajesh-cicd-website.s3-website-us-east-1.amazonaws.com/

## Key Features
- Zero manual deployment needed
- Secure credential management via GitHub Secrets
- Automatic deployment on every push
- Fast and reliable delivery
